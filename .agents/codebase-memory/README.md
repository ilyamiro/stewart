## Quick Usage

### Via Helper Script (`.agents/bin/cbm`)

A preconfigured CLI wrapper is available at `.agents/bin/cbm`:

```bash
# Architecture summary
.agents/bin/cbm get_architecture

# Search symbols (functions, classes, variables, modules)
.agents/bin/cbm search_graph --name-pattern ".*audio.*"

# Trace function call chains (inbound/outbound)
.agents/bin/cbm trace_path --function-name "main" --direction both

# Retrieve code snippet by qualified name
.agents/bin/cbm get_code_snippet --qualified-name "home-ilyamiro-Projects-stewart.main.main"

# Re-index the codebase after changes
.agents/bin/cbm reindex
```
